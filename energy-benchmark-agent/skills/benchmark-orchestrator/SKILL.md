# Skill: Benchmark Orchestrator

## Scopo

Orchestrare l'esecuzione di tutti i tool di intervento energetico su un modello
energetico in input, raccogliere i risultati e generare la relazione finale.

## Da completare

- [ ] Logica di selezione interventi applicabili (in base ai dati disponibili nel modello)
- [ ] Riferimenti ai tool disponibili nel registry
- [ ] Gestione errori parziali (un intervento fallisce, gli altri continuano)
- [ ] Parametri di configurazione (regione, anno, interventi da includere/escludere)
- [ ] Output: percorso del file .docx generato
